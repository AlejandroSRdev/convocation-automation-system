# STACK DEFINITION — V1

## Backend
- **Python 3.12**
- **FastAPI**
- **SQLAlchemy 2.x**
- **Alembic**

## Database
- **PostgreSQL**

## Frontend
- **HTML**
- **CSS**
- **Vanilla JavaScript**

## AI Layer
- **OpenAI API**
  - Optional refinement only (human-in-the-loop)

## Messaging / Delivery
- **WhatsApp API Provider**
  - Twilio Sandbox or UltraMsg (V1)

## Infrastructure
- **Docker**
- **Fly.io** (backend deployment)
- **Vercel** (frontend deployment)

## Observability
- **Structured logging**

---

## Explicitly Excluded From V1
- **React**
- **LangChain / LangGraph**
- **Microservices**
- **Complex workflow engines**
- **Autonomous AI systems**
- **Premature infrastructure complexity**
